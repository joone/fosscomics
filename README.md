# F/OSS Comics

F/OSS Comics tells stories from the history of computing and free and open
source software. The series uses illustrated, conversational articles to make
the people, ideas, and technical changes behind modern software approachable.

Read the web edition at [fosscomics.com](https://fosscomics.com), or read the
English and Korean Markdown editions directly on GitHub. Each episode directory
contains both languages when a Korean edition is available.
